# 当代人工智能实验二：搜索算法

本仓库为《当代人工智能》实验二的代码实现，主要包含 A* 搜索算法、Minimax 算法以及 Alpha-Beta 剪枝算法的实现与对照实验。

## 📌 环境要求
- Python 3.8 及以上版本
- 无需安装任何第三方依赖库（仅使用 Python 标准库：`heapq`, `json`, `math`, `typing`）

## 📂 目录结构
- `lab2.py`：包含全部四个题目的核心算法实现及测试用例入口。
- `README.md`：项目说明文档。

## 🚀 运行方式
在终端或命令行中进入项目目录，直接运行：
```bash
python lab2.py
